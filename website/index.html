Safe by design. Supported to 2028.

Zurbax 2.1 is a long-term support release. Security updates arrive every two weeks until October 2028, signed and checked before they install, and one restart finishes them.

  • Every 2 weeks

    Security updates

    The newest long-term Linux kernel and fixes for the system, every other Tuesday. They install on their own.

  • Signed

    Checked before they install

    Each update is signed by Zurbax and every file checked against its fingerprint. A tampered one is thrown away.

  • Lockdown

    A kernel nothing can change

    Not even the administrator can rewrite the running kernel or read its memory.

  • ASLR

    Nothing in the same place twice

    Every program loads at a random address, with stack canaries and zeroed memory to stop attacks early.

  • Sandbox

    Apps kept apart

    Apps can't read each other's memory, and Flatpak apps get only what they're given.

  • Private

    Nothing collected

    No telemetry, no ads, no account needed, and nothing on Zurbax listens to the network.

From download to desktop in four steps.

Every detail, from boot menu keys to games and fixing problems, is in the guide.

  1. 1

    Download

    One image works on every PC made in the last twelve years. It holds the drivers, the apps and Steam.

  2. 2

    Make the stick

    Open balenaEtcher or Rufus, pick the file and a 16 GB USB stick, and press Flash.

  3. 3

    Start from it

    Restart, open the boot menu (F12, F8 or Esc) and choose the stick. Zurbax opens to a desktop you can try.

  4. 4

    Install

    Choose Install Zurbax, pick a disk, set a name and password. A few minutes later it's yours.
